# Ngirupp Tuak website

Static one-page site for Ngirupp (Yearly-Based Tuak, Kuching). Open `index.html` in a browser, or host the folder on any static host (GitHub Pages, Netlify, etc.).

- Flavour list, prices and descriptions live in the `FLAVOURS` array in `index.html`.
- Set `WHATSAPP_NUMBER` (country code, digits only, e.g. `60123456789`) in `index.html` so the Order form opens WhatsApp.
- Product photos in `images/` were cropped from the flavour-list posters; swap in higher-resolution photos with the same file names for sharper images.
